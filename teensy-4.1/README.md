# Teensy 4.1

بخش پروژه‌های مرتبط با **Teensy 4.1**.

## درباره برد

Teensy 4.1 یک برد توسعهٔ پرسرعت با هستهٔ ARM Cortex-M7 است؛ مناسب پردازش سنگین، صدا، ویدئو، شبکه و پروژه‌هایی که به قدرت محاسباتی و پورت‌های زیاد نیاز دارند.

## مشخصات کلی

| مورد | مقدار |
|------|--------|
| **پردازنده** | NXP i.MX RT1062 (ARM Cortex-M7) |
| **فرکانس** | ۶۰۰ مگاهرتز |
| **RAM** | ۱ مگابایت (۵۱۲ کیلوبایت tightly coupled) |
| **فلش** | ۷۹۳۶ کیلوبایت (۸ مگ) |
| **EEPROM** | ۴ کیلوبایت (امولیشن) |
| **ولتاژ کاری** | ۳٫۳ ولت |
| **ابعاد** | حدود ۲٫۴ × ۰٫۷ اینچ |

### ارتباطات سریال (UART)

| پورت | RX | TX |
|------|----|----|
| Serial1 | 0 | 1 |
| Serial2 | 7 | 8 |
| Serial3 | 15 | 14 |
| Serial4 | 16 | 17 |
| Serial5 | 21 | 20 |
| Serial6 | 25 | 24 |
| Serial7 | 28 | 29 |
| Serial8 | 34 | 35 |

(در برخی نسخه‌ها ممکن است نقش RX/TX جابهجا باشد؛ دفترچه پین رسمی PJRC را چک کن.)

### SPI

| پورت | SCK | MOSI | MISO | CS/SS |
|------|-----|------|------|-------|
| SPI (پیش‌فرض) | 13 | 11 | 12 | 10 |

### I2C

| پورت | SDA | SCL |
|------|-----|-----|
| Wire (پیش‌فرض) | 18 | 19 |
| Wire1 | 16 | 17 |
| Wire2 | 24 | 25 |

(در محیط آردوینو اغلب SDA0=14, SCL0=15 استفاده می‌شود؛ به بورد پک و نسخهٔ Teensyduino وابسته است.)

### CAN

| پورت | TX | RX |
|------|----|----|
| CAN1 | 3 | 4 |
| CAN2 | 29 | 30 |
| CAN3 (CAN FD) | 33 | 34 |

### پاور و سخت‌افزار خاص

| پین | توضیح |
|-----|--------|
| 3.3V | خروجی ۳٫۳V |
| GND | زمین |
| VIN | ورودی ولتاژ (۳٫۶–۶V توصیه شده) |
| **Ethernet** | پورت اترنت 10/100 با PHY داخلی (پین‌های مخصوص روی برد) |
| **SD Card** | اسلات کارت SD (SDIO 4-bit) روی برد |
| **USB** | یک پورت USB Device و یک پورت USB Host (۴۸۰ Mbit/s) |

توصیه: برای نقشهٔ دقیق و موقعیت فیزیکی هر پین، از [صفحهٔ پین‌اوت رسمی PJRC](https://www.pjrc.com/teensy/pinout.html) و PDFهای **card11a_rev4_web.pdf** و **card11b_rev4_web.pdf** استفاده کن.
