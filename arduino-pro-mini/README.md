# Arduino Pro Mini

بخش پروژه‌های مرتبط با **Arduino Pro Mini**.

## درباره برد

آردوینو پرو مینی برد کوچک و کم‌حجم برای نصب ثابت و پروژه‌های فشرده است. پورت USB ندارد و با آداپتور USB-to-Serial (مثلاً FTDI) برنامه‌ریزی می‌شود.

## دو نسخهٔ ولتاژی

| نسخه | فرکانس | ولتاژ ورودی |
|------|--------|-------------|
| **۳٫۳V** | ۸ مگاهرتز | ۳٫۳–۱۲ ولت |
| **۵V** | ۱۶ مگاهرتز | ۵–۱۲ ولت |

حتماً نسخهٔ برد خود را چک کنید تا ولتاژ و فرکانس را درست تنظیم کنید.

## مشخصات کلی

| مورد | مقدار |
|------|--------|
| **میکروکنترلر** | ATmega328P |
| **حافظه فلش** | ۳۲ کیلوبایت |
| **SRAM** | ۲ کیلوبایت |
| **EEPROM** | ۱ کیلوبایت |
| **پین دیجیتال I/O** | ۱۴ (۶ عدد با PWM) |
| **ورودی آنالوگ** | ۶ پین |
| **جریان هر پین I/O** | حداکثر ۴۰mA |
| **هدر برنامه‌ریزی** | ۶ پین (نیاز به آداپتور FTDI/USB-Serial) |

---

## نقشه پین‌ها (Pinout)

چیدمان پین مثل نانو است؛ دو ردیف در دو طرف. **هدر ۶پین** برای برنامه‌ریزی: VCC, GND, RXI, TXO, DTR, RST.

### ردیف پین‌ها (سمت آنالوگ / پاور)

| پین | نام در آردوینو | توضیح |
|-----|----------------|--------|
| RAW | VIN / RAW | ورودی ولتاژ خام (قبل از رگولاتور) |
| GND | GND | زمین |
| GND | GND | زمین |
| VCC | VCC | خروجی ولتاژ تنظیم‌شده (۳٫۳V یا ۵V بسته به برد) |
| VCC | VCC | همان |
| RST | RESET | ریست |
| RXI | D0 / RX | دریافت سریال (به TX آداپتور وصل شود) |
| TXO | D1 / TX | ارسال سریال (به RX آداپتور وصل شود) |
| 2 | D2 | دیجیتال ۲ — اینتراپت (INT0) |
| 3 | D3 | دیجیتال ۳ — **PWM** — اینتراپت (INT1) |
| 4 | D4 | دیجیتال ۴ |
| 5 | D5 | دیجیتال ۵ — **PWM** |
| 6 | D6 | دیجیتال ۶ — **PWM** |
| 7 | D7 | دیجیتال ۷ |
| 8 | D8 | دیجیتال ۸ |
| 9 | D9 | دیجیتال ۹ — **PWM** |
| 10 | D10 | دیجیتال ۱۰ — **PWM** — **SS** (اسپای) |
| 11 | D11 | دیجیتال ۱۱ — **PWM** — **MOSI** |
| 12 | D12 | دیجیتال ۱۲ — **MISO** |
| 13 | D13 | دیجیتال ۱۳ — **SCK** — LED داخلی |
| A0 | A0 | ورودی آنالوگ ۰ |
| A1 | A1 | ورودی آنالوگ ۱ |
| A2 | A2 | ورودی آنالوگ ۲ |
| A3 | A3 | ورودی آنالوگ ۳ |
| A4 | A4 | ورودی آنالوگ ۴ / **SDA** (I2C) |
| A5 | A5 | ورودی آنالوگ ۵ / **SCL** (I2C) |

### هدر ۶پین برنامه‌ریزی (FTDI)

| پین هدر | عملکرد |
|---------|--------|
| VCC | ۳٫۳V یا ۵V (مطابق برد) — به VCC آداپتور |
| GND | زمین — به GND آداپتور |
| RXI | RX برد (داده از آداپتور) — به **TX** آداپتور |
| TXO | TX برد (داده به آداپتور) — به **RX** آداپتور |
| DTR | Data Terminal Ready — برای ریست هنگام آپلود (اغلب از طریق خازن به RST) |
| RST | ریست |

### خلاصه کاربرد پین‌ها

| کاربرد | پین‌ها |
|--------|--------|
| **PWM** | D3, D5, D6, D9, D10, D11 |
| **UART** | D0 (RX), D1 (TX) — و هدر FTDI |
| **I2C** | A4 (SDA), A5 (SCL) |
| **SPI** | D10 (SS), D11 (MOSI), D12 (MISO), D13 (SCK) |
| **اینتراپت خارجی** | D2 (INT0), D3 (INT1) |
| **ورودی آنالوگ** | A0–A5 |

## محیط توسعه

- [Arduino IDE](https://www.arduino.cc/en/software): برد **Arduino Pro or Pro Mini**، Processor **ATmega328P (3.3V, 8 MHz)** یا **(5V, 16 MHz)**.
- آپلود از طریق پورت سریال (FTDI یا مبدل USB-Serial).
