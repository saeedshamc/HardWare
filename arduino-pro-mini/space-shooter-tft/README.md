# بازی کشتی فضایی — Arduino Pro Mini + HW-504 + TFT

بازی شوتر ساده با جویستیک **HW-504** و نمایشگر **TFT SPI** (تراشه ST7735، معمولاً ۱٫۸ اینچ).

## سخت‌افزار

| قطعه | توضیح |
|------|--------|
| **Arduino Pro Mini** | ۵V / ۱۶MHz یا ۳٫۳V / ۸MHz |
| **HW-504** | جویستیک دو محوره آنالوگ + دکمه |
| **TFT 1.8"** | ST7735، ارتباط SPI |

## سیم‌کشی

### جویستیک HW-504 → پرو مینی

| HW-504 | Arduino Pro Mini |
|--------|-------------------|
| GND    | GND               |
| +5V    | VCC (یا ۳٫۳V برای برد ۳٫۳V) |
| VRx    | **A0**            |
| VRy    | **A1**            |
| SW     | **D2**            |

### TFT (ST7735) → پرو مینی

| TFT | Arduino Pro Mini |
|-----|-------------------|
| GND | GND               |
| VCC | ۳٫۳V یا ۵V (بسته به ماژول) |
| CS  | **D10**           |
| DC  | **D8**            |
| RST | **D9**            |
| MOSI| **D11**           |
| SCK | **D13**           |
| LED | ۳٫۳V یا ۵V (پس‌زمینه) |

> اگر برد شما ۵V است و TFT فقط ۳٫۳V می‌گیرد، روی خطوط سیگنال (CS, DC, RST) مقاومت حدود ۱kΩ سری بگذارید.

## کتابخانه‌ها

از **Arduino IDE** → **Sketch** → **Include Library** → **Manage Libraries** نصب کنید:

1. **Adafruit GFX Library**
2. **Adafruit ST7735 and ST7789 Library**

## آپلود روی کنترلر (ریختن برنامه روی آردوینو)

آردوینو پرو مینی خودش پورت USB ندارد؛ با یک **آداپتور USB-to-Serial** (مثلاً FTDI یا CH340) به کامپیوتر وصلش کن.

### اتصال آداپتور به پرو مینی (هدر ۶پین)

| پین پرو مینی (هدر برنامه‌ریزی) | آداپتور USB-Serial |
|--------------------------------|---------------------|
| VCC  | ۵V یا ۳٫۳V (مطابق نسخهٔ برد) |
| GND  | GND |
| RXI  | **TX** آداپتور (داده از کامپیوتر به برد) |
| TXO  | **RX** آداپتور (داده از برد به کامپیوتر) |
| DTR  | معمولاً از طریق خازن ۱۰۰nF به RST |
| RST  | ریست (اختیاری؛ برای آپلود خودکار به DTR وصل می‌شود) |

> **توجه:** RX برد به TX آداپتور و TX برد به RX آداپتور وصل شود (تقاطع).

### مراحل در Arduino IDE

1. **باز کردن پروژه**  
   از منو: **File** → **Open** و پوشهٔ `space-shooter-tft` را باز کن (یا فایل `space_shooter_tft.ino`).

2. **انتخاب برد**  
   **Tools** → **Board** → **Arduino AVR Boards** → **Arduino Pro or Pro Mini**.

3. **انتخاب پروسسور**  
   **Tools** → **Processor**:
   - اگر برد **۵V** است: **ATmega328P (5V, 16 MHz)**  
   - اگر برد **۳٫۳V** است: **ATmega328P (3.3V, 8 MHz)**

4. **انتخاب پورت**  
   **Tools** → **Port** → پورتی که آداپتور USB-Serial روی آن است (مثلاً `COM3` در ویندوز یا `/dev/ttyUSB0` در لینوکس).  
   اگر پورتی نمی‌بینی، درایور CH340/FTDI را نصب کن.

5. **آپلود**  
   دکمه **Upload** (فلش به راست) را بزن یا **Ctrl+U**.  
   در پایین IDE باید «Done uploading» را ببینی.

بعد از آپلود، آداپتور را می‌توانی جدا کنی و برد را با منبع تغذیهٔ جدا (۵V یا ۳٫۳V مطابق برد) به همراه جویستیک و TFT روشن کنی.

## ساختار ماژولاری (فایل‌های .h و .cpp)

| فایل | نقش |
|------|------|
| **config.h** | پین‌ها، ابعاد صفحه، ثابت‌های بازی (یک منبع حقیقت) |
| **joystick_hw504.h / .cpp** | ماژول جویستیک HW-504؛ `joystick_init()`, `joystick_read()` |
| **game.h / .cpp** | وضعیت بازی (`GameState`) و منطق؛ `game_init()`, `game_update()` |
| **display_tft.h / .cpp** | رسم روی TFT؛ `display_init()`, `display_draw_*`, `display_clear_*` |
| **space_shooter_tft.ino** | فقط `setup()` و `loop()`؛ هماهنگی ماژول‌ها |

وابستگی: `display_tft` از `game` (برای `GameState`) و `config` استفاده می‌کند. `game` فقط به `config` وابسته است. جویستیک مستقل است.

## نحوه بازی

- **جویستیک**: حرکت کشتی (چپ/راست/بالا/پایین).
- **دکمه جویستیک (SW)**: شلیک.
- دشمنان از بالا می‌آیند؛ با گلوله بزنید تا امتیاز بگیرید.
- اگر دشمن به کشتی برخورد کند یا از پایین فرار کند، بازی تمام می‌شود.
- برای شروع دوباره بعد از Game Over، دکمه شلیک را بزنید.

## تنظیمات اختیاری

همهٔ ثابت‌ها در **config.h** هستند؛ با تغییر آن فایل می‌توانید تنظیم کنید:

- `JOY_DEAD_ZONE`: حساسیت جویستیک (عدد بزرگ‌تر = ناحیه مرده بیشتر).
- `BULLET_MAX` / `ENEMY_MAX`: تعداد هم‌زمان گلوله و دشمن.
- `BULLET_SPEED`, `ENEMY_SPEED`, `ENEMY_SPAWN_MS`: سرعت و اسپان.
- اگر نوع TFT با `INITR_BLACKTAB` کار نکرد، در **display_tft.cpp** داخل `display_init()` از `INITR_GREENTAB` یا `INITR_18REDTAB` استفاده کنید (مطابق مستندات Adafruit).
