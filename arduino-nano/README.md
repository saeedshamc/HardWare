# Arduino Nano

بخش پروژه‌های مرتبط با **Arduino Nano**.

## درباره برد

آردوینو نانو نسخهٔ فشردهٔ یونو است؛ همان هستهٔ ATmega328P با ابعاد کوچک و مناسب برای بردبورد و پروژه‌های فشرده.

## مشخصات کلی

| مورد | مقدار |
|------|--------|
| **میکروکنترلر** | ATmega328P (8-bit AVR) |
| **فرکانس** | ۱۶ مگاهرتز |
| **حافظه فلش** | ۳۲ کیلوبایت |
| **SRAM** | ۲ کیلوبایت |
| **EEPROM** | ۱ کیلوبایت |
| **ولتاژ کاری** | ۵ ولت |
| **ولتاژ ورودی (VIN)** | ۶–۱۲ ولت (۷–۱۲ توصیه می‌شود) |
| **ابعاد PCB** | حدود ۱۸ × ۴۳ میلی‌متر |
| **اتصال USB** | Mini-B (در نسخه‌های جدید ممکن است USB-C باشد) |

## نقشه پین‌ها (Pinout)

دو ردیف پین در دو طرف برد؛ از سمت USB به سمت جلو، ردیف **بالا** و **پایین**.

### ردیف بالا (از چپ به راست، سمت USB)

| پین روی برد | نام در آردوینو | توضیح |
|-------------|----------------|--------|
| 1 | D1 / TX | **UART TX** |
| 2 | D0 / RX | **UART RX** |
| 3 | RESET | ریست |
| 4 | GND | زمین |
| 5 | D2 | دیجیتال ۲ — اینتراپت (INT0) |
| 6 | D3 | دیجیتال ۳ — **PWM** — اینتراپت (INT1) |
| 7 | D4 | دیجیتال ۴ |
| 8 | D5 | دیجیتال ۵ — **PWM** |
| 9 | D6 | دیجیتال ۶ — **PWM** |
| 10 | D7 | دیجیتال ۷ |
| 11 | D8 | دیجیتال ۸ |
| 12 | D9 | دیجیتال ۹ — **PWM** |
| 13 | D10 | دیجیتال ۱۰ — **PWM** — **SS** (اسپای) |
| 14 | D11 | دیجیتال ۱۱ — **PWM** — **MOSI** |
| 15 | D12 | دیجیتال ۱۲ — **MISO** |
| 16 | D13 | دیجیتال ۱۳ — **SCK** — **LED داخلی** |
| 17 | 3V3 | خروجی ۳٫۳V |
| 18 | AREF | مرجع آنالوگ |
| 19 | A0 | ورودی آنالوگ ۰ |
| 20 | A1 | ورودی آنالوگ ۱ |
| 21 | A2 | ورودی آنالوگ ۲ |
| 22 | A3 | ورودی آنالوگ ۳ |
| 23 | A4 | ورودی آنالوگ ۴ / **SDA** (I2C) |
| 24 | A5 | ورودی آنالوگ ۵ / **SCL** (I2C) |
| 25 | A6 | ورودی آنالوگ ۶ (فقط آنالوگ) |
| 26 | A7 | ورودی آنالوگ ۷ (فقط آنالوگ) |
| 27 | 5V | خروجی ۵V |
| 28 | GND | زمین |
| 29 | VIN | ورودی ولتاژ |

### ردیف پایین

مطابق همان ترتیب، ردیف دوم موازی با ردیف بالا است (پین‌های مشترک برای بردبورد).

### خلاصه کاربرد پین‌ها

| کاربرد | پین‌ها |
|--------|--------|
| **PWM** | D3, D5, D6, D9, D10, D11 |
| **UART** | D0 (RX), D1 (TX) |
| **I2C** | A4 (SDA), A5 (SCL) |
| **SPI** | D10 (SS), D11 (MOSI), D12 (MISO), D13 (SCK) |
| **اینتراپت خارجی** | D2 (INT0), D3 (INT1) |
| **ورودی آنالوگ** | A0–A7 (A0–A5 دیجیتال هم دارند؛ A6, A7 فقط آنالوگ) |
| **جریان مجاز هر پین I/O** | حدود ۲۰–۴۰mA |
