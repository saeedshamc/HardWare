# Arduino Uno R3

بخش پروژه‌های مرتبط با **Arduino Uno R3**.

## درباره برد

آردوینو یونو R3 یکی از پرکاربردترین بردهای توسعه مبتنی بر AVR است و برای یادگیری و پروژه‌های عمومی ایده‌آل است.

## مشخصات کلی

| مورد | مقدار |
|------|--------|
| **میکروکنترلر** | ATmega328P (8-bit AVR) |
| **فرکانس** | ۱۶ مگاهرتز |
| **حافظه فلش** | ۳۲ کیلوبایت |
| **SRAM** | ۲ کیلوبایت |
| **EEPROM** | ۱ کیلوبایت |
| **ولتاژ کاری** | ۵ ولت |
| **ولتاژ ورودی (VIN)** | ۶–۲۰ ولت |

---

## نقشه پین‌ها (Pinout)

### هدر سمت راست (پاور و آنالوگ)

| پین روی برد | نام در آردوینو | توضیح |
|-------------|----------------|--------|
| NC | — | بدون اتصال |
| IOREF | IOREF | ولتاژ مرجع I/O (۵V) |
| RESET | RESET | ریست (فعال با LOW) |
| 3.3V | 3V3 | خروجی ۳٫۳V (حداکثر ۵۰mA) |
| 5V | 5V | خروجی ۵V |
| GND | GND | زمین |
| GND | GND | زمین |
| VIN | VIN | ورودی ولتاژ (۶–۲۰V وقتی از آداپتور استفاده می‌کنی) |
| A0 | A0 | ورودی آنالوگ ۰ |
| A1 | A1 | ورودی آنالوگ ۱ |
| A2 | A2 | ورودی آنالوگ ۲ |
| A3 | A3 | ورودی آنالوگ ۳ |
| A4 | A4 | ورودی آنالوگ ۴ / **SDA** (I2C) |
| A5 | A5 | ورودی آنالوگ ۵ / **SCL** (I2C) |
| AREF | AREF | ولتاژ مرجع آنالوگ |

### هدر سمت چپ (دیجیتال)

| پین روی برد | نام در آردوینو | توضیح |
|-------------|----------------|--------|
| 0 | D0 / RX | دیجیتال ۰ — **UART RX** (دریافت سریال) |
| 1 | D1 / TX | دیجیتال ۱ — **UART TX** (ارسال سریال) |
| 2 | D2 | دیجیتال ۲ — **اینتراپت خارجی (INT0)** |
| 3 | D3 | دیجیتال ۳ — **PWM** — اینتراپت خارجی (INT1) |
| 4 | D4 | دیجیتال ۴ |
| 5 | D5 | دیجیتال ۵ — **PWM** |
| 6 | D6 | دیجیتال ۶ — **PWM** |
| 7 | D7 | دیجیتال ۷ |
| 8 | D8 | دیجیتال ۸ |
| 9 | D9 | دیجیتال ۹ — **PWM** |
| 10 | D10 | دیجیتال ۱۰ — **PWM** — **SS** (اسپای) |
| 11 | D11 | دیجیتال ۱۱ — **PWM** — **MOSI** (اسپای) |
| 12 | D12 | دیجیتال ۱۲ — **MISO** (اسپای) |
| 13 | D13 | دیجیتال ۱۳ — **SCK** (اسپای) — **LED داخلی** |
| GND | GND | زمین |
| AREF | AREF | مرجع آنالوگ |

### خلاصه کاربرد پین‌ها

| کاربرد | پین‌ها |
|--------|--------|
| **PWM** | D3, D5, D6, D9, D10, D11 |
| **UART** | D0 (RX), D1 (TX) |
| **I2C** | A4 (SDA), A5 (SCL) |
| **SPI** | D10 (SS), D11 (MOSI), D12 (MISO), D13 (SCK) |
| **اینتراپت خارجی** | D2 (INT0), D3 (INT1) |
| **ورودی آنالوگ** | A0 تا A5 |
| **جریان مجاز هر پین I/O** | حداکثر ۲۰mA |
