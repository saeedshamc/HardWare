# 🎮 بازی اول ESP32 - نسخه کامل با سپر

یک بازی 2 بعدی پیشرفته که روی برد ESP32 اجرا می‌شود و از طریق WiFi قابل دسترسی است. این نسخه شامل سیستم سپر، جوی استیک موبایل و ویژگی‌های پیشرفته است.

## ✨ ویژگی‌های جدید

### 🎯 گیم‌پلی پیشرفته
- **سیستم سطح**: با افزایش امتیاز، سطح بازی بالا می‌رود
- **دشمنان**: از سطح 2 به بعد، دشمنان قرمز ظاهر می‌شوند
- **آیتم‌های متنوع**: 4 نوع آیتم با امتیازهای مختلف (10-25 امتیاز)
- **سیستم سپر**: محافظت 10 ثانیه‌ای با هزینه 50 امتیاز

### 🎮 کنترل‌های پیشرفته
- **جوی استیک موبایل**: کنترل دایره‌ای برای موبایل
- **دکمه سپر موبایل**: دکمه اختصاصی برای فعال کردن سپر
- **کنترل کیبورد**: WASD + کلید P برای سپر
- **ریسپانسیو کامل**: سازگار با تمام دستگاه‌ها

### 🎨 طراحی بصری
- **ذرات انفجاری**: افکت‌های بصری هنگام جمع‌آوری
- **انیمیشن پالسی**: آیتم‌ها با انیمیشن پالسی
- **سپر بصری**: دایره آبی دور بازیکن هنگام فعال بودن سپر
- **رابط مدرن**: طراحی زیبا و کاربرپسند

## نحوه استفاده

### 1. آماده‌سازی ESP32


1. برد ESP32 را به کامپیوتر وصل کنید
2. Arduino IDE را باز کنید
3. کتابخانه‌های زیر را نصب کنید:
   - ESP32 Board Package
   - WebServer library

### 2. تنظیمات WiFi

در فایل `esp32_game_server.ino` خطوط زیر را ویرایش کنید:

```cpp
const char* ssid = "نام_شبکه_وایفای_شما";
const char* password = "رمز_عبور_وایفای_شما";
```

### 3. آپلود کد

1. فایل `esp32_game_server.ino` را در Arduino IDE باز کنید
2. برد ESP32 را انتخاب کنید
3. کد را آپلود کنید

### 4. اتصال به بازی

1. Serial Monitor را باز کنید (115200 baud)
2. آدرس IP نمایش داده شده را یادداشت کنید
3. در مرورگر آدرس `http://IP_ADDRESS` را وارد کنید

## 🎮 نحوه بازی

### 🎯 انواع آیتم‌ها:
| نماد | رنگ | امتیاز | توضیحات |
|------|-----|--------|----------|
| ⭐ | طلایی | 10 | آیتم پایه |

### 🎮 کنترل‌ها:

#### **دسکتاپ**:
- **حرکت**: `WASD` یا کلیدهای جهت‌دار
- **جمع‌آوری**: `Space`
- **سپر**: `P` (نیاز به 50 امتیاز)

#### **موبایل**:
- **جوی استیک**: کشیدن knob برای حرکت
- **دکمه سپر**: کلیک برای فعال کردن سپر
- **دکمه‌های روی صفحه**: برای عملیات مختلف

### 🏆 اهداف بازی:
1. **جمع‌آوری آیتم‌ها**: برای کسب امتیاز
2. **اجتناب از دشمنان**: از سطح 2 به بعد
3. **استفاده از سپر**: برای نابودی دشمنان و کسب امتیاز
4. **رسیدن به سطوح بالاتر**: با کسب هر 100 امتیاز

### ⚡ سیستم سپر:
- **هزینه**: 50 امتیاز
- **مدت**: 10 ثانیه
- **تأثیر**: نابودی دشمنان و کسب 30 امتیاز اضافی
- **نمایش**: دایره آبی دور بازیکن

## 🔌 API Endpoints

- `GET /`: صفحه اصلی بازی
- `GET /api/game-state`: دریافت وضعیت فعلی بازی (شامل آیتم‌ها، دشمنان، سپر)
- `POST /api/move`: حرکت بازیکن
- `POST /api/toggle-game`: شروع/توقف بازی
- `POST /api/score`: افزایش امتیاز
- `POST /api/shield`: فعال کردن سپر (نیاز به 50 امتیاز)
