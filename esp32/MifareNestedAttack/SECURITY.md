# Security & Ethics

## Allowed use

- Cards you own
- Instructor-provided laboratory cards
- Explicitly authorized security research

## Forbidden use

- Access cards belonging to other people
- University / workplace / hotel / transit / payment cards without authorization
- Cloning or modifying cards to bypass real access control

## What this project will not do

- Real Nested / Darkside key recovery against unknown keys
- Turning RC522 into a Proxmark3-class attack platform
- Shipping default tooling aimed at unauthorized access

Educational simulators explain *why* legacy Crypto1 designs failed; they are not cracking kits.

## Reporting

If you find a mistake that would enable unsafe misuse in classroom defaults, open an issue and describe the defensive fix.
