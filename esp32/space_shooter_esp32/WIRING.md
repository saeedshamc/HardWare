# سیم‌کشی

## نمایشگر TFT ۱.۸ اینچ (ST7735) به ESP32

| پین نمایشگر | پین ESP32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| CS | GPIO 5 |
| RESET (RST) | GPIO 4 |
| A0 (DC) | GPIO 2 |
| SDA (MOSI) | GPIO 23 |
| SCK | GPIO 18 |
| LED (بک‌لایت) | 3V3 |

## جوی‌استیک HW-504 به ESP32

| پین جوی‌استیک | پین ESP32 |
|---|---|
| GND | GND |
| +5V | **3V3** |
| VRx | GPIO 34 |
| VRy | GPIO 35 |
| SW | GPIO 32 |

## نکته‌های مهم

- **پین +5V جوی‌استیک را به 3V3 وصل کن، نه 5 ولت.** ورودی‌های آنالوگ ESP32 ولتاژ بالای 3.3 ولت را تحمل نمی‌کنند.
- پین‌های 34 و 35 فقط ورودی هستند و از ADC1 می‌آیند؛ برای خواندن جوی‌استیک مناسب‌اند.
- پین‌های SPI نمایشگر (MOSI = 23 و SCK = 18) همان VSPI سخت‌افزاری هستند و ثابت‌اند.
- پین‌های CS، RST و DC قابل تغییرند، ولی باید در کد (بالای فایل `.ino`) هم عوض شوند.
- اگر نور بک‌لایت خیلی زیاد بود، یک مقاومت حدود ۱۰۰ اهم سری پین LED کن.
