# بازی Space Shooter روی ESP32 (نسخه ۲ - با آیتم‌ها)

بازی کشتی فضایی برای **ESP32-WROOM-32** با نمایشگر **TFT ۱.۸ اینچ (ST7735، ۱۲۸×۱۶۰)** و **جوی‌استیک HW-504**.

## محتویات پکیج

```
space_shooter_esp32/
├── README.md                    ← همین راهنما
├── WIRING.md                    ← جدول سیم‌کشی و شماتیک متنی
└── space_shooter/
    └── space_shooter.ino        ← کد کامل بازی
```

## ویژگی‌ها

- حرکت کشتی در چهار جهت با جوی‌استیک
- تیراندازی همیشه خودکار
- ۳ جان، امتیاز، بالاترین امتیاز، مرحله‌های سخت‌تر
- دشمن‌های معمولی و دشمن‌های قوی‌تر که تیراندازی می‌کنند
- **آیتم‌های تصادفی** که دشمن‌های نابود‌شده بعضی وقت‌ها از خودشان به جا می‌گذارند (پایین‌تر توضیح داده شده)
- پس‌زمینه ستاره‌ای متحرک، انفجار، چشمک‌زدن بعد از برخورد
- بدون فلیکر (رسم روی بافر داخلی و ارسال یکجا به نمایشگر)

## نیازمندی‌ها

- Arduino IDE
- پکیج برد **esp32 by Espressif Systems** (از Boards Manager)
- کتابخانه‌ها (از Library Manager):
  - `Adafruit GFX Library`
  - `Adafruit ST7735 and ST7789 Library`
  - اگر پرسید، وابستگی‌ها (Adafruit BusIO) را هم نصب کن (Install all)

## مراحل نصب و اجرا

1. سیم‌کشی را طبق `WIRING.md` انجام بده.
2. پوشه `space_shooter` را از داخل زیپ بیرون بیاور. نام پوشه باید با نام فایل `.ino` یکی باشد.
3. فایل `space_shooter.ino` را در Arduino IDE باز کن.
4. از Tools → Board برد **ESP32 Dev Module** و از Tools → Port پورت درست را انتخاب کن.
5. **به جوی‌استیک دست نزن** و ESP32 را روشن کن؛ کد موقع روشن شدن وسط جوی‌استیک را کالیبره می‌کند.
6. دکمه Upload را بزن. اگر روی `Connecting...` گیر کرد، دکمه BOOT روی برد را نگه دار.
7. بعد از آپلود، صفحه عنوان بازی نمایش داده می‌شود. با دکمه جوی‌استیک (یا کشیدن استیک) بازی را شروع کن.

## آیتم‌ها

| آیتم | ظاهر | اثر |
|---|---|---|
| ارتقای سلاح | جعبه نارنجی با حرف **W** | سطح سلاح +۱ (حداکثر ۴) |
| جان اضافه | قلب قرمز | ۱+ جان (حداکثر ۵) |
| تیر سریع | جعبه فیروزه‌ای با حرف **R** | ۸ ثانیه تیراندازی دو برابر سریع‌تر |

- سطح ۱: تک تیر | سطح ۲: دو تیر موازی | سطح ۳: سه تیر (وسط + دو طرف پخش) | سطح ۴: دو تیر موازی + دو تیر پخش
- وقتی ضربه می‌خوری، علاوه بر از دست دادن یک جان، سطح سلاح هم یک پله پایین می‌آید.
- اگر سلاح یا جان در حداکثر باشد و آیتم بگیری، ۵۰ امتیاز می‌گیری.
- سطح سلاح و زمان تیر سریع در ردیف دوم بالای صفحه نمایش داده می‌شود.
- شانس افتادن آیتم در بالای فایل `.ino` قابل تنظیم است.

## کنترل‌ها

| ورودی | عملکرد |
|---|---|
| جوی‌استیک | حرکت کشتی |
| تیراندازی | همیشه خودکار |
| دکمه SW (یا کشیدن استیک) | شروع / شروع دوباره |

## تنظیمات (بالای فایل `.ino`)

| تنظیم | کاربرد |
|---|---|
| `INVERT_X` / `INVERT_Y` | اگر جهت چپ/راست یا بالا/پایین برعکس بود `true` کن |
| `DEADZONE` | اگر کشتی خودش حرکت می‌کند عدد را بیشتر کن (مثلاً ۴۰۰ تا ۵۰۰) |
| `PLAYER_SPEED` | سرعت کشتی |
| `FIRE_DELAY` | فاصله بین تیرها به میلی‌ثانیه (کمتر = تندتر) |
| `START_LIVES` | تعداد جان‌ها |
| `MAX_LIVES` | حداکثر جان |
| `DROP_WEAPON` / `DROP_LIFE` / `DROP_RAPID` | درصد شانس افتادن هر آیتم (جان کم‌تر از بقیه است) |
| `RAPID_MS` | مدت تیر سریع (میلی‌ثانیه) |

## عیب‌یابی

- **صفحه سفید:** سیم‌های CS، DC و RST را دوباره چک کن.
- **صفحه سیاه:** پین LED نمایشگر به 3V3 وصل نیست، یا SDA/SCK جابه‌جا شده‌اند.
- **رنگ‌ها اشتباه یا نوار نویز کنار صفحه:** در تابع `setup` به جای `INITR_BLACKTAB` از `INITR_GREENTAB` یا `INITR_REDTAB` استفاده کن.
- **تصویر آینه‌ای یا چرخیده:** عدد `setRotation(0)` را بین ۰ تا ۳ تغییر بده.
- **کشتی خودش حرکت می‌کند:** `DEADZONE` را زیاد کن و موقع روشن کردن دست به جوی‌استیک نزن.
- **جهت‌ها برعکس است:** `INVERT_X` یا `INVERT_Y` را عوض کن.
- **دکمه SW کار نمی‌کند:** مشکلی نیست، با کشیدن استیک هم بازی شروع می‌شود.
- **خطای Connecting... موقع آپلود:** دکمه BOOT را نگه دار.
- **اگر GPIO 2 مشکل ساخت (موقع آپلود):** پین DC را روی GPIO 16 ببر و در کد `TFT_DC` را عوض کن.
