# 🏎️ بازی ماشین ESP32 - نسخه کامل

یک بازی ماشین پیشرفته و جذاب که روی برد ESP32 اجرا می‌شود و از طریق WiFi قابل دسترسی است. این نسخه شامل ماشین‌های دشمن، 100 باکس امتیاز متنوع و ویژگی‌های پیشرفته است.

## ✨ ویژگی‌های جدید

### 🚗 گیم‌پلی پیشرفته
- **ماشین‌های دشمن**: 3 ماشین قرمز که باید از آن‌ها دوری کنید
- **100 باکس امتیاز**: 4 نوع باکس با امتیازهای مختلف (10-25 امتیاز)
- **سیستم برخورد**: برخورد با دشمنان باعث از دست دادن امتیاز می‌شود
- **سرعت بالا**: حداکثر سرعت 20 واحد

### 🎯 انواع باکس‌های امتیاز
| نماد | رنگ | امتیاز | توضیحات |
|------|-----|--------|----------|
| + | طلایی | 10 | باکس پایه |
| ★ | قرمز | 20 | باکس باارزش |
| ♦ | بنفش | 15 | باکس متوسط |
| ● | سبز | 25 | باکس نادر |

### 🎮 کنترل‌های پیشرفته
- **کنترل کامل ماشین**: گاز، ترمز، تغییر لاین
- **سیستم جاده**: 3 لاین با خطوط مشخص
- **ریسپانسیو کامل**: سازگار با تمام دستگاه‌ها
- **کنترل چندگانه**: دکمه‌ها و کیبورد

## نحوه استفاده

### 1. آماده‌سازی ESP32

1. برد ESP32 را به کامپیوتر وصل کنید
2. Arduino IDE را باز کنید
3. کتابخانه‌های زیر را نصب کنید:
   - ESP32 Board Package
   - WebServer library

### 2. تنظیمات WiFi

در فایل `esp32_car_game.ino` خطوط زیر را ویرایش کنید:

```cpp
const char* ssid = "نام_شبکه_وایفای_شما";
const char* password = "رمز_عبور_وایفای_شما";
```

### 3. آپلود کد

1. فایل `esp32_car_game.ino` را در Arduino IDE باز کنید
2. برد ESP32 را انتخاب کنید
3. کد را آپلود کنید

### 4. اتصال به بازی

1. Serial Monitor را باز کنید (115200 baud)
2. آدرس IP نمایش داده شده را یادداشت کنید
3. در مرورگر آدرس `http://IP_ADDRESS` را وارد کنید

## نحوه بازی

### کنترل‌ها:

#### دکمه‌های روی صفحه:
- **🚗 گاز**: افزایش سرعت ماشین
- **🛑 ترمز**: کاهش سرعت ماشین
- **⬅️ چپ**: تغییر به لاین چپ
- **➡️ راست**: تغییر به لاین راست

#### کنترل با کیبورد:
- `W` یا `↑`: گاز
- `S` یا `↓`: ترمز
- `A` یا `←`: تغییر لاین به چپ
- `D` یا `→`: تغییر لاین به راست

### 🏆 اهداف بازی:
1. **جمع‌آوری باکس‌ها**: 4 نوع باکس با امتیازهای مختلف
2. **اجتناب از دشمنان**: از 3 ماشین قرمز دوری کنید
3. **کنترل سرعت**: حداکثر سرعت 20 واحد
4. **استفاده از لاین‌ها**: 3 لاین برای حرکت و فرار

### ⚠️ قوانین بازی:
- **برخورد با دشمن**: از دست دادن امتیاز
- **جمع‌آوری باکس**: کسب امتیاز (10-25 امتیاز)
- **سرعت بالا**: خطر بیشتر اما هیجان بیشتر
- **تغییر لاین**: برای فرار از دشمنان

## API Endpoints

- `GET /`: صفحه اصلی بازی
- `GET /api/game-state`: دریافت وضعیت فعلی بازی
- `POST /api/car-control`: کنترل ماشین (گاز، ترمز، تغییر لاین)
- `POST /api/toggle-game`: شروع/توقف بازی
- `POST /api/update-game`: به‌روزرسانی وضعیت بازی
