# سیم‌کشی Hozur (ESP32)

## نکات ایمنی

1. **RC522 فقط ۳٫۳ ولت** است. VCC را به ۵V وصل نکنید؛ آسیب دائمی می‌دهد.
2. سیم‌های SPI را کوتاه نگه دارید (ترجیحاً کمتر از ۱۰–۱۵ سانتی‌متر).
3. زمین مشترک (GND) بین ESP32، RC522، TFT و تغذیه الزامی است.
4. قفل/رله/آکتواتور را از تغذیه جداگانه تغذیه کنید؛ فقط سیگنال (از طریق ترانزیستور/اپتوکوپلر) از ESP32 بیاید.
5. جریان کل USB را در نظر بگیرید؛ برای TFT + RC522 بهتر است منبع ۳٫۳V/۵V خارجی پایدار داشته باشید.

## جدول پین‌ها (پیش‌فرض `config.h`)

### RC522 — VSPI

| سیگنال RC522 | GPIO ESP32 | توضیح |
|--------------|------------|--------|
| SDA (SS) | 5 | Chip Select |
| SCK | 18 | VSPI SCK |
| MOSI | 23 | VSPI MOSI |
| MISO | 19 | VSPI MISO |
| RST | 22 | Reset |
| VCC | 3V3 | فقط ۳٫۳V |
| GND | GND | |

### TFT ILI9341 — HSPI

| سیگنال TFT | GPIO ESP32 | توضیح |
|------------|------------|--------|
| SCK | 14 | HSPI SCK |
| MOSI | 13 | HSPI MOSI |
| MISO | 12 | اختیاری (خواندن) |
| CS | 15 | Chip Select |
| DC | 2 | Data/Command |
| RST | 4 | Reset |
| VCC | 3V3 یا ۵V | بسته به ماژول |
| LED/BLK | 3V3 یا PWM | بک‌لایت |
| GND | GND | |

> پین‌های TFT در `config.h` قابل تغییرند. از GPIOهای ۶–۱۱ استفاده نکنید (فلش داخلی).

### سایر

| قطعه | GPIO | توضیح |
|------|------|--------|
| Buzzer | 27 | اکتیو یا پسیو با ترانزیستور |
| Status LED | 25 | |
| Mode button | 32 | ورودی؛ pull-up داخلی؛ به GND فشار دهید |
| DS3231 SDA | 21 | اختیاری |
| DS3231 SCL | 26 | اختیاری (۲۲ برای RSTِ RC522 رزرو شده) |

## دیاگرام ASCII

```
                 +3.3V ----+---- RC522 VCC
                           +---- TFT VCC (اگر 3.3V)
                           +---- DS3231 VCC (اختیاری)
  ESP32 DevKit             |
  -----------              |
  GPIO5  ---------------> RC522 SS
  GPIO18 ---------------> RC522 SCK
  GPIO23 ---------------> RC522 MOSI
  GPIO19 <--------------- RC522 MISO
  GPIO22 ---------------> RC522 RST

  GPIO14 ---------------> TFT SCK
  GPIO13 ---------------> TFT MOSI
  GPIO12 <--------------- TFT MISO (اختیاری)
  GPIO15 ---------------> TFT CS
  GPIO2  ---------------> TFT DC
  GPIO4  ---------------> TFT RST

  GPIO27 ---------------> Buzzer (+)
  GPIO25 ---------------> LED (+)
  GPIO32 <---[btn]--- GND   Mode

  GPIO21 ---------------> DS3231 SDA
  GPIO26 ---------------> DS3231 SCL

  GND  -----------------+---- همه GNDها
```

## تداخل باس

- RC522 روی **VSPI** و TFT روی **HSPI** هستند تا CS جداگانه و تداخل کمتر باشد.
- هنگام استفاده از هر دستگاه، CS دیگری را HIGH نگه دارید (کد فریم‌ویر این کار را می‌کند).
