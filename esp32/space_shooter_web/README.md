# بازی Space Shooter روی ESP32 (نسخه وب، برای موبایل)

ESP32 خودش یک وای‌فای می‌سازد و بازی را روی یک صفحه وب نشان می‌دهد. تو با گوشی به وای‌فایش وصل می‌شوی، صفحه را باز می‌کنی و با انگشت بازی می‌کنی.

**هیچ سیم‌کشی و قطعه اضافه‌ای لازم نیست.** فقط خود ESP32 و یک کابل USB (یا پاوربانک).

## محتویات پکیج

```
space_shooter_web/
├── README.md
├── index.html                  ← همان بازی؛ برای تست روی کامپیوتر دابل‌کلیک کن
└── space_shooter_web/
    ├── space_shooter_web.ino   ← کد ESP32 (وب‌سرور)
    └── index_html.h            ← صفحه بازی که ESP32 به گوشی می‌دهد
```

نکته: هر دو فایل `.ino` و `index_html.h` باید داخل یک پوشه به نام `space_shooter_web` باشند. وقتی `.ino` را باز کنی، `index_html.h` خودش به‌صورت یک تب کنار آن دیده می‌شود.

## مراحل نصب

1. فایل `space_shooter_web/space_shooter_web.ino` را در Arduino IDE باز کن.
2. برد را روی **ESP32 Dev Module** و پورت را روی پورت درست بگذار. کتابخانه اضافه‌ای لازم نیست (`WiFi` و `WebServer` با پکیج ESP32 می‌آیند).
3. دکمه **Upload** را بزن. اگر روی `Connecting......` ماند، دکمه **BOOT** را نگه دار.
4. بعد از آپلود، چراغ آبی روی برد روشن می‌شود (یعنی سرور آماده است).

## نحوه بازی

1. در گوشی به وای‌فای **SpaceShooter** وصل شو. رمز: **12345678**
2. مرورگر (Chrome یا Safari) را باز کن و این آدرس را بزن: **`http://192.168.4.1`**
   (حتماً با `http://` شروع کن، نه https)
3. روی صفحه بزن تا بازی شروع شود.
4. **انگشتت را روی صفحه بکش** تا کشتی حرکت کند. یک جوی‌استیک شناور زیر انگشتت ظاهر می‌شود. تیراندازی همیشه خودکار است.
5. دکمه کوچک بلندگو پایین سمت راست صدا را قطع و وصل می‌کند.

روی کامپیوتر هم می‌شود با کلیدهای جهت‌دار یا WASD بازی کرد (برای تست).

## ویژگی‌ها

- جوی‌استیک لمسی شناور و تیراندازی همیشه خودکار
- ۳ جان، امتیاز، مرحله، بالاترین امتیاز (روی خود گوشی ذخیره می‌شود)
- دشمن‌های معمولی و قوی‌تر که تیراندازی می‌کنند
- صدا و لرزش گوشی هنگام برخورد (لرزش فقط روی بعضی گوشی‌های اندروید)
- آیتم‌های تصادفی که از دشمن‌ها می‌افتد:

| آیتم | ظاهر | اثر |
|---|---|---|
| ارتقای سلاح | جعبه نارنجی **W** | سطح سلاح +۱ (حداکثر ۴) |
| جان | قلب قرمز | ۱+ جان (حداکثر ۵) |
| تیر سریع | جعبه فیروزه‌ای **R** | ۸ ثانیه تیراندازی دو برابر سریع‌تر |

سطح سلاح: ۱ تک تیر، ۲ دو تیر، ۳ سه تیر پخش، ۴ دو تیر + دو تیر پخش. وقتی ضربه می‌خوری یک سطح سلاح پایین می‌آید.

## تنظیمات

### تغییر نام و رمز وای‌فای
بالای فایل `.ino`:
```cpp
const char* AP_SSID = "SpaceShooter";
const char* AP_PASS = "12345678";   // حداقل ۸ کاراکتر
```

### وصل شدن به وای‌فای خانه (به‌جای ساختن وای‌فای)
```cpp
#define USE_HOME_WIFI true
const char* HOME_SSID = "اسم وای‌فای خانه";
const char* HOME_PASS = "رمز وای‌فای خانه";
```
بعد از آپلود، **Serial Monitor** را روی 115200 باز کن. آدرس IP نوشته می‌شود (مثلاً `http://192.168.1.50`). گوشی هم باید به همان وای‌فای وصل باشد. اگر ۱۵ ثانیه وصل نشد، برد خودش به حالت ساختن وای‌فای برمی‌گردد.

### تنظیم‌های بازی
بالای بخش `<script>` در فایل `index.html` (و همین‌طور در `index_html.h`) ثابت‌هایی مثل `PS` (سرعت کشتی)، `FIRE` (سرعت تیراندازی)، `START_LIVES` و درصد شانس افتادن آیتم‌ها (`DROP_W` و `DROP_L` و `DROP_R`) هست. بعد از هر تغییر در `index.html`، باید محتوای تغییریافته را در `index_html.h` هم بگذاری، چون ESP32 فقط `index_html.h` را می‌فرستد.

## عیب‌یابی

- **گوشی می‌گوید «اینترنت ندارد» و قطع می‌شود:** از پیام گوشی گزینه **Stay connected / نگه داشتن اتصال** را بزن. بهتر است اینترنت موبایل را موقتاً خاموش کنی تا گوشی به‌خاطر نبود اینترنت از وای‌فای نپرد.
- **صفحه باز نمی‌شود:** آدرس را دقیقاً `http://192.168.4.1` بزن. بعضی مرورگرها خودشان `https` می‌گذارند و باید حذفش کنی.
- **وای‌فای SpaceShooter را نمی‌بینم:** برد را یک بار ریست کن (دکمه EN) و ۵ ثانیه صبر کن. مطمئن شو رمز حداقل ۸ کاراکتر است.
- **بازی کند یا پرش‌دار است:** برنامه‌های سنگین پس‌زمینه را ببند و مطمئن شو فقط یک گوشی وصل است. ESP32 فقط صفحه را می‌فرستد و خود بازی روی گوشی اجرا می‌شود، پس سرعت به گوشی بستگی دارد.
- **صدا ندارد:** مرورگر صدا را بعد از اولین لمس فعال می‌کند. یک بار روی صفحه بزن و دکمه بلندگو را چک کن.
- **خطای آپلود یا Connecting......:** دکمه BOOT را نگه دار، کابل را عوض کن، Upload Speed را روی 115200 بگذار.
